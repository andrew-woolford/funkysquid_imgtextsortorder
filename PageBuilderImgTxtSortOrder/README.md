# Two-Column Layout with Image & Text columns and Desktop Order Selector
The Two-Column Layout module for Adobe Commerce Page Builder provides a flexible and customisable solution for creating engaging and visually appealing pages.

This module allows you to effortlessly arrange content in a two-column format, with one column dedicated to an image and the other for textual content.

Additionally, it features a desktop order selector, giving you the control to define the order of columns specifically for desktop view, ensuring an optimal layout and user experience across devices.

## Key Features:
- **Two-Column Design:** Image Column: Display high-quality images to capture visitors’ attention.
Content Column: Add rich text, headings, buttons, and other content elements.
- **Desktop Order Selector:** Customisable Order: Easily switch the position of the image and content columns for desktop view.
Responsive Design: Automatically adjusts the layout for mobile and tablet devices, ensuring a seamless experience on all screen sizes.
- **User-Friendly Interface:** Drag-and-Drop Functionality: Intuitive interface for arranging and customising content without any coding knowledge.
Styling Options: Customise fonts, colours, and backgrounds to match your brand’s aesthetic.
- **SEO-Friendly:** Structured Content: Proper HTML structure to improve SEO performance and accessibility.
- **Performance Optimised:** Lazy Loading: Ensure faster page load times by lazy loading images.

## Benefits:
- **Enhanced Flexibility:** Easily adjust column order for different devices to create the most effective layout.
- **User-Friendly:** No coding skills required—build and customise your layouts with a simple drag-and-drop interface.
- **SEO and Performance:** Structured content and lazy loading features ensure your pages are optimised for search engines and have fast load times.
- **Versatile Applications:** Ideal for a variety of uses, including product highlights, about us sections, testimonials, and more.

## Configuration:
- **Add the Two-Column Layout:** Drag the Two-Column Layout block into your page.
- **Configure Image Column:** Upload an image or choose from your media library.
Set alignment, padding, and other display settings.
- **Configure Content Column:** Add text, headings, buttons, and other content elements.
Customise styles such as fonts, colours, and background.
- **Set Desktop Order:** Use the Desktop Order Selector to choose the desired order of columns for desktop view.
- **Save and Preview:** Save your changes and preview the layout on different devices to ensure responsiveness and aesthetic appeal.

## Use Cases:

### Example 1: Product Highlight Section
Objective: Create a section to highlight a specific product with an image on the left and descriptive content on the right.
- Image Column: Add a high-resolution image of the product.
- Content Column: Include a product title, description, price, and a “Buy Now” button.
Desktop Order Selector: Set the image column to display on the left and the content on the right for desktop view.

### Example 2: About Us Section
Objective: Create an engaging “About Us” section with a company image and a descriptive paragraph.
- Image Column: Add a professional photo of the team or office.
- Content Column: Write a brief history of the company, mission statement, and core values.
Desktop Order Selector: Set the content column to display on the left and the image on the right for desktop view.

### Example 3: Testimonial Section
Objective: Showcase a customer testimonial with the customer’s photo and their feedback.
- Image Column: Add a photo of the customer.
- Content Column: Include the customer’s name, testimonial, and rating.
Desktop Order Selector: Choose to display the customer’s photo on the left and their testimonial on the right for desktop viewing.
